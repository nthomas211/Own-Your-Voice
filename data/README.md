# Data

Large ASL datasets should **not** be committed directly to this GitHub repository.

Use this folder for documentation, small metadata files, or scripts that describe how datasets are obtained and prepared.
Research notes about candidate datasets are stored in:

`docs/asl_research/dataset_sources.docx`

Recommended practice:

- keep raw video datasets outside Git or in approved storage;
- document dataset source, license, consent, and allowed uses;
- keep train/validation/test partitions reproducible;
- do not upload participant recordings or personally identifying research data without appropriate permission;
- do not commit derived files that are too large for normal Git workflows.
